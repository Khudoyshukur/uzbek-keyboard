# Uzbek Latin keyboard (Özbekça klaviatura)

A keyboard layout for the updated Uzbek Latin alphabet: **Ö ö, Ğ ğ, Ş ş, Ç ç** and the apostrophe **ʼ** (U+02BC).

Website and Cyrillic ↔ Latin ↔ new Latin converter: **[uzbek-keyboard.safix.uz](https://uzbek-keyboard.safix.uz)**
It's standard US QWERTY. Hold **Option ⌥** (macOS) or **AltGr / Right Alt** (Windows, Linux) and press `o g s c '`. Add Shift for capitals.

## Install

| OS | Command |
|---|---|
| macOS (Terminal) | `curl -fsSL https://raw.githubusercontent.com/khudoyshukur/uzbek-keyboard/main/macos/install.sh \| bash` |
| Windows (PowerShell) | `irm https://raw.githubusercontent.com/khudoyshukur/uzbek-keyboard/main/windows/get.ps1 \| iex` |
| Linux | `curl -fsSL https://raw.githubusercontent.com/khudoyshukur/uzbek-keyboard/main/linux/install.sh \| sh` |

Each command downloads the latest release, installs it, and enables it. Afterwards, log out and back in on macOS and Linux.
To remove it, add `--uninstall`; on Windows, add `-Uninstall`. The [install guides](docs/) (in Uzbek) have the exact commands.
You can also download the files directly from [Releases](https://github.com/khudoyshukur/uzbek-keyboard/releases/latest).

Contributing: all layout files are generated by `tools/generate.py`. See [docs/development.md](docs/development.md).
